SimpleChatServer는 WebSocket을 활용한 고성능 실시간 채팅 플랫폼입니다. 사용자 인증, 채팅방 관리, 메시지 검색 등 다양한 기능을 제공합니다.

주요 기능

JWT 인증

안전한 JWT 토큰 기반 사용자 인증 시스템

실시간 메시징

WebSocket 기반 실시간 메시지 송수신

채팅방 관리

다중 채팅방 생성 및 사용자 권한 관리
